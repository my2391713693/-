# 世界背景与地理

架空古代，宋宛与燕昭宁均为本世成长的人物；唯一超常现象为帝相定期互换身体。这里记录稳定地理与制度；已发生事件、个案数额及凭据去向见[连续性表](连续性核对表.md)。未启用地区仅作可用背景。

## 同劳玦与现实边界

御府保存开国君臣共誓旧礼的一对同劳玦，立契后仅对两位应誓者生效，具体规则统一见[帝相互换设定](帝相互换设定.md)。1～4章已写结契回顾、首次互换和旧录查明，器物收封与次数查连续性表。

世界没有可供人物日常调用的法术体系，不能由一对玉玦推导出其他换魂器物、妖术组织或天命鉴定。多数人仍把共誓当作旧礼寓意；发现异常须从行为与亲见建立，不会人人随口猜到换魂。旧礼的来历不改变先帝死亡、遗诏真伪与帝位合法性。

公众按身体所见识别皇帝与左相，官印、宫门、军令和官署仍按本职运转。互换只移动意识，异地消息、物资、人员与正式命令仍受正常交通和传递限制；无人因占用另一具身体自动知道对方见过的人或掌握过的军情。

## 政权与行政

| 政权 | 方位、都城与特点 |
|---|---|
| 燕国 | 大陆中北部，燕京；河谷农田、北部山口、西陲走廊与东部海岸，立国约百年，中央财紧、勋贵隐田与边镇坐大 |
| 梁国 | 燕南，建康；水网、粮食、丝织与河运，邦交通商并有边贸竞争 |
| 越国 | 东南，临海；海港、造船、海盐与远洋贸易，争海运关税 |
| 凉国 | 西方，武威；绿洲、马匹、铜铁和关道，曾争西陲，现暂稳 |
| 朔庭 | 北方，北庭；王庭统合部族，畜牧、皮毛、药材与边市，时战时贸；又称朔国、北庭 |

外国备用区域：梁为建康府、江州、淮州、湖州，对应建宁、浔阳、寿春、吴兴；越为临海府、明州、台州、泉州，对应海安、定海、临津、晋江；凉为武威府、沙州、肃州、庭州，对应姑臧、敦煌、酒泉、昌宁；朔庭为北庭王畿、东原、西原、南帐，代表地为北庭城、白川城、乌石口、南帐边市。

燕采用朝廷—道—州或京府—县—乡里。道管巡察、驿路与钱粮汇核，州由知州主政，县令掌户籍田赋；燕京府与州同级。军镇管驻防供应，与地方民政并存。

## 京城与货路地点

- 燕京在北方平原南缘、河转陆运处。宫城居北，太极殿大朝，紫宸殿与御书房召见；户部等在宫外皇城官署区。
- 宋府在皇城西南官宅区，与宋家旧宅是两处；韩宅在城西旧巷，齐陆府在内城东部。女学距宋府半日内，有讲堂、后院及学舍，具体街坊未定。
- 南平码头在京南。德顺栈在码头巷、停业三年；同兴由码头北街迁沿河石桥，栈前街有修船铺。“北街”为街名。
- 西营小厅用于三方核饷，西门外有米铺、豆腐铺及马家赁屋。常演路经运水车道，换值点旁矮墙遮视线，营后有土坡。
- 九门为内外城联防军门体系；寝宫门户另归禁军。夜间入宫须御召或特许宫牌。
- 礼部偏厅承办具名受荐及本人愿见的会面，所求、登记与回条留部。文津书坊所在地及存续未定。
- 京晋段由同兴承运；晋宁西门外通泰栈六年前停业、旧址木器铺，旧东家赁后街修箱。兴和在晋宁东街，北程转石城石岘栈。前屯、北屯为平朔不同营，北屯在大营北面。

京中日常去处还包括影戏棚、布摊、西面的脂粉巷与城南秋日卖菊的花棚，具体字号和街坊未定。初夏旧友步行看戏，15章姐妹在宋府附近看夜场，不据此推定两处同棚或跨城距离。启元元年初夏民间影戏已开，宫中仍循服丧礼序；市井小戏与宫廷庆宴分别安排。

## 路程与消息

里为架空路程单位，估算约半公里；天气、车数和关卡造成的延误在正文交代。

| 路线 | 常态距离与用时 |
|---|---|
| 燕京—平河 | 南向约300里；普通队伍4～6日，快马1～2日 |
| 燕京—晋宁—平朔 | 北向900～1000里；轻装7～9日，驿递3～5日，车队12～16日 |
| 燕京—青州 | 经并州东侧岔道向东北，官差7～10日 |
| 燕京—汾州 | 东向偏北接河东驿路，官差5～8日 |
| 燕京—西陲凉州 | 西向关道，官差12～18日 |
| 燕京—柳林 | 本差单程6日，县州往返各1日，20日差牌含来回 |
| 平朔大营—落雁峡 | 东北30里；轻骑半日内，粮车半日至一日 |
| 朔阳永裕—落雁峡 | 本批粮车一日 |
| 平朔城南转运仓—落雁峡 | 粮车约一日，经城外沟桥，县中承修 |

落雁峡在燕境内，是山间商道转折与仓粮分流口，朔庭边界在更北。驻营可控制贸易补给；长期驻扎、增兵及改变粮源须报。城南转运仓为民政库，大营军需库、北屯和峡仓各立账。

## 官署与军政

| 机构 | 职责 |
|---|---|
| 皇帝 | 最终人事、财政特令、跨镇调兵及军政处置 |
| 中书省、左相 | 统筹政务、拟诏、协调奏报与奉旨督办 |
| 户部 | 户籍田赋、度支、核销与物资拨付 |
| 兵部 | 军籍军需、调防文牍和执行手续 |
| 枢密院 | 汇核军情与布防建议，奉御命发跨镇军令 |
| 御史台 | 巡察、弹劾、复勘及监督取证 |
| 刑部、大理寺 | 刑部审理，大理寺复核重大案件 |
| 礼部 | 礼制、科举、婚仪及册封章程 |
| 宗正寺 | 皇族谱牒、婚姻、封王与年例审核；宗正府指寺卿私宅 |
| 内务司 | 宫廷物料、宫人档册与内廷采购 |

九门册额四万二，首验西营六百；平朔册额十万，分关、屯、骑与辎重各营。册额与实兵分别核。城门军、宫禁和藩邸护卫各有统属。

跨镇调防须正式军令、兵部执行与粮饷转拨或明定暂支，御前、枢密及兵部留底。镇内巡边常例可小规模调度，长期改驻另报。左相协调、郎中经手、后妃入宫各依本职，无自动兵权。

三方核饷保原页，错栏附正；军籍、月饷、伤恤及一次临济分别核。问退卒避开当值，原票调取给凭据，代领人和本人分别答。

## 女学、皇族与婚产

女学提供教育，女子获科举资格后与男子同榜取士，授实职经选任；同批入学与同科进士分别记。女学之后可入仕、教书或成家，婚后外任与照料仍须各人解决。

皇女原可受王爵、招赘和参政；皇位旧例以皇子为常，燕昭宁为首位女帝。皇嗣一般成年就藩，未成年可特旨安排。册封依御定、颁告命、承领次第落实。

女帝后宫为成年男子入宫，正位皇夫、常位良人，良人可多人。正式诏书用位分，“纳妃”“男妃”为统称。旧妃居太妃区，良人居指定院；奉差凭御封，起居与家书循常例。韩本次省亲持宫符午后出、入暮归，出入依准许登记。

婚事须本人同意，成婚不自动失官。嫁资田核原契、田号、四至及交付，县册可附正本人户名，代管另列；核名后照纳税，当季佃约续行。柳林本次官田安置为四亩三年耕，期限依本牍；民田产权另核。

## 钱粮与账制

- 粮用石、斗，银用两，铜钱用文；峡营本次10斗合1石，日额4石含口粮灶用，马料另算。粮价、斤石及银铜比随场景统一。
- 田分官田、民田、军屯及有诏免赋田。隐田为应登未登；平河限期如实自报免旧隐田税、当年照实亩纳，分期与原佃约分别核。
- 盐为官许经营，铁料及军用铁器登记许可、流向；普通农具不一律禁。长丰经营皮毛、药材及军需，查案分货价、脚钱、折银与佣钱。
- 军府抵税票须朝廷授权，粮入营、税簿已输、县库实银分别核。各仓、县库、驿站和馆驿各存经手记录。
- 德顺记入栈包数、承运及最终回单后销讫；同兴车簿记本段起止、交货押，回票簿记领票押。账制依商号各自做法。
