# 人物关系与个人情节规划

以下为改写方向。固定身份见[人物关系](人物关系定稿.md)，已写性格与经历见[人物档案](人物背景与关联.md)。目标是让读者持续关心每个人自己的日子，人物重现时承接上次的愿望与选择。

## 互换进入个人生活

[互换设定](帝相互换设定.md)已在前30章实施；下表前段为已立处境，亲密、许知情等后续仍待正文。现有生活按“已写”列核对，不把一切宋的聚会都改成燕代去。

| 组合 | 新处境与连续后果 | 保留谁自己的生活 |
|---|---|---|
| 宋、燕与宋父 | 燕以宋身接训话也收送书，未代应初五饭；宋本人回家共饭，父女仍有旧隔阂。今后燕能帮一次，也不能代替亲近 | 父女旧伤由宋本人再见、再赴约面对，不让女帝代替亲近 |
| 燕与许姜梁 | 燕听朋友抱怨皇帝，越为自己辩白越不像宋；许要她兑现旧安排，梁照自己的课时先走 | 姜有外任与看海的愿望，梁有课、家人与新裙，许有母亲和实差，均非皇帝的民情答问人 |
| 宋、燕与齐韩 | 宋以帝身收荐帖、躲新私约，燕换回后须亲自赴约；宫中人会为反复失约和态度差别不快 | 政治合作与亲近分别发展，齐韩有权追问、拒绝和作自己的选择 |
| 许与宋、燕 | 许中段亲见换回才明确知情，先问哪些承诺是宋本人作的，不立即帮二人瞒人 | 朋友重新争信任与界限，许仍争自己的职位、归期和休息 |
| 帝相彼此 | 对方的差事答应起来容易，自己的新增日程到来才后悔；有嘴硬、补课、互相回敬和一起庆功 | 生活麻烦有轻重，骑射答问可以闹，婚约、亲密和生死不可拿来报复 |

朋友本人的聚会与姐妹往来必须继续。原来的看戏、买香、探母等好场景不一律改成“燕冒充宋参加”，宋也有不想让皇帝插手的兴趣与关系。每回不必帮谁破案，身份笑话之外还可以单纯贪嘴、爱美、较劲与想歇。

## 三组持续来往的人

| 组合 | 关系中的张力 | 怎样连续展开 |
|---|---|---|
| 宋、许、姜、梁的女学旧友 | 许既信宋又想挣脱宋相提携的评价；宋肯护许也享受被依赖；姜重仕途，梁珍惜教学与家庭 | 聚会由各人的事发起；姜梁单独来往，宋晚到便先听。领差、回京、教学和饭约各有回收 |
| 宋宜、宋宛、顾衡与宋父 | 姐姐有妹妹缺过的嫡女体面，妹妹有姐姐难得的自主；宋父得益于女儿又放不下旧偏见 | 姐妹先有日常往来，再接田产；夫妻直接争经营与族情，父女关心和旧伤逐步变化 |
| 沈家、秦家及宫中家人 | 沈正顾家族、沈蘅保孩子；秦护旧部也重权威；韩想亲近女帝也想家 | 按继位、核饷、纳人的阶段突出相应关系，家人直接交锋，选择影响公事 |

一段稳定突出三至五人，优先使用现有亲缘与同窗。小人物保留鲜明所求，不给人人另开身世长线。

## 私人生活怎样接续

政治是持续主轴，人物也有同朝局无关的欲望、旧交与家事。轻松喜剧是这些相处的常态，闲闹有动作、有来回，不总转为感伤或自省。生活场景按他们自己的日子生长，朋友能在宋不在时聊衣裳、谈远游，亲人会为一次失约不高兴，对手回家也有亲近的人。一次闲聊无须解决矛盾，一件小物也不必变成证据或象征。

| 人物关系 | 已写的私人生活 | 后续方向，尚待落实正文 |
|---|---|---|
| 宋宛自己的闲乐 | 1～2问书案价、听停俸先心疼；5抬太傅旧桌仍惦记自己的宽案；12同姐出游后订案、多要一个藏点心的薄抽屉；15新案已送来，先给姐姐看蜜糕 | 小气、馋嘴、爱漂亮和好胜都保留自己的后续，不把每种兴趣变成公事本领或人格教育 |
| 温与故君、曹慎 | 5想把先帝少年用过的课桌搬进书房，舍不得桌底丑画；拆装搬入后椅子挡门，曹进出还被嫌胖，念旧与家中小执拗并存 | 再见时带着他自己的作息、念旧与不耐烦；对故君的感情影响选择，不能每次只等宋来求背书 |
| 姜、梁与女学旧友 | 10四人看影戏赌杏、姜怕鬼嘴硬，梁买浅青布，姜梁返女学私谈海与衣色。29梁穿浅青裙，燕用宋身同姜帮忙反乱，姜自拟请调、纸沾宋袖；燕没代定差，宋换回后得知 | 相聚承接出游、衣着、教学和各自家庭，不每次都开成议事。看海愿望与争差相关但各自有意义，尚无出行安排 |
| 宋宜与宋宛 | 12姐姐主动约逛脂粉巷，妹妹试浓香；15姐妹同时把香油推给对方，油仍留下、绣雀帕送姐，吃饭看戏又被邻座问香，仍须重新问喜好 | 与田产并行写姐妹自己的往来；顾衡42章亲登前，夫妻私事只由姐姐转述，不能抢先把二人写成共同登场 |
| 许与母亲、宋与许母 | 12母亲试新鞋、问花样，盼着相约看菊；许定好出差行程却没先告知改约，母女未立即释怀；14母已同邻人买花，宋捉虫却碰落好叶，母将这事写进信，许回信仍忍不住追问花价。20许挑新笔归家讲丢鞋，母有自己的菊花、分花种与邻人看花之约，女儿先歇满一日；22母女灯下看新印，母嘴硬没多说却让女儿穿官服等邻人还碗，26送行后母与邻人买糕看花 | 母亲有自己的邻里和乐趣；许争实差也舍不得母亲。40、92归家继续承接，不只备饭、包干粮、夸左相 |
| 齐绍与父亲、女帝；韩家父子与女帝 | 16同脸画像辨不清，齐绍要自己把话说完，18亲领须知，25成礼后谢凳、共膳各挑菜、照转父亲求缓家信，回居所读自己想读的游园短文；17韩家父子买鱼留饭、直说父伤与夜灯，18本人奉召应问，25父亲送儿入宫仍惦记鱼汤，燕将替父记姜错当本人偏好 | 后续依家书、日常口味与本人请求继续亲近，政治合作和家人牵挂不一次说理便解决 |
| 郑家父子与另一房堂弟、赵家旧交 | 15父子争添粮仓与租牛，堂弟欠种粮不愿跟报；郑记赵家旧恩，赴宴想说合，15出庄后缓添仓、问别家牛，自家契自己交 | 后续若重现，接实际租牛与分水的进展，不把免旧税写成已替他解决来年所有农事，也不将堂弟视为已报田 |
| 陆靖与赵氏、赵氏与兄长 | 14家中柿饼、丈夫缺牙、送嫁旧事与烤栗记忆成立；赵氏直认向阿兄，却不愿丈夫胡乱作保 | 旧情、亲缘和家族利益共同影响护短，二人也会为普通日子留时辰；家常不代替公事上的证据和责任 |

后续优先从已有人物的生活继续，不给每人新添惨事或秘密身世。允许他们偏袒、嫉妒、冲动、不体谅，也保留热心、喜欢与无用的小乐趣；当下未说开，可以以后再碰，不急着由旁白解释。

## 各人追什么

| 人物 | 欲望与短处 | 个人故事的变化 |
|---|---|---|
| 宋宛 | 想证明自己，也想无事可办时仍被需要；容易把照顾做成接管 | 从替人排路，到能参与别人生活、尊重各自选择，也保有自己的兴趣与去处 |
| 许明砚 | 想要署自己名字的实绩和职位；争强、不肯轻易说累 | 主动争差、独自决定与受挫，任用与责任相称；旧友关系容得下竞争，归期由自己答母亲 |
| 姜令仪 | 想自己决定仕途与婚后生活，也想被认真欣赏；会替朋友认定好路 | 理解梁的所得；遇到好人仍可能不合适，失望后继续过日子 |
| 梁素 | 想教出会算的学生，保住收入、家人与自己的时间；小忙接多才发火 | 为教法争条件，自己商量家内照料，也承认羡慕朋友的见识与名声 |
| 宋宜 | 想经营自己的田，又想维持夫妻日子；怕伤和气，也会低估经营 | 从托人说情到亲自跑田，承担误判、收麦和工钱；顾衡实际承担族中压力 |
| 燕昭宁 | 想掌握能执行的君权，也想被主动选择；习惯命令，夹有控制与依赖 | 学会约定和等待，允许亲近的人另有去处；政事和私情中都能作错选择 |
| 秦武 | 想保营盘、旧部和威望；信熟人、倚旧法，怕当年轻文臣面认错 | 亲自发现并处理问题，保守兵利益，也承担自己的签责 |
| 韩知微 | 想被喜欢、顾家人、保一点自由；好面子，盼别人发现不快 | 从只报平安到能说想家、提出请求，也主动回应女帝 |

温与燕允礼保留旧交间的分歧，谢与许逐渐形成同事默契，周为查访者的饭碗作一次实际取舍。背景借已有经历、物件和眼前决定显露。

## 公事与私人生活的交接

- 许12主动争差、13受阻实报、14获续差读家书、15取得实绩记协办，职业所求与对母亲的牵挂同时存在。20、22承归家任用；40、41再返京，49漏录补正留考核。
- 宋宜12只取租收分项、15仍未核名，34才转求自主持契，42夫妻亲自呈县；后续核名、收麦与工钱均依正文。姐妹出门、夫妻私下口味与日常来往另有自己的后续。
- 秦在2章为守兵催原额粮、10章背景中与宋议正常饷照发、兵卒换值后由三署分批直接核问，旧名领饷由后续现场接起；本事与护兵立场成立，后续继续检验签责。秦家亲缘与家人初登依人物关系表，不提前安排。
- 姜梁仍只知公开差事，不随聚会获知军中密报。梁夫女仍77章首次亲登，早段的家内照料只由梁转述。

生活场景也可以只写一次乐趣与牵挂，人物不必每次都有关系转折，暂时不理解彼此也成立。喜剧写法接[趣味规划](趣味与冲突规划.md)，拟议章位与分段速度由重构规划集中维护，改写取舍接[前100章规划](前100章重构规划.md)，首次出场及新增经历随正文同步。
