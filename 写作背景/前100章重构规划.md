# 前100章重构规划

核心为[帝相互换](帝相互换设定.md)：轻松喜剧贯穿朝政和生活，互换引出身份麻烦、真实立场与联手反制。现有1～100章均为正式正文，尚未落入互换；其真实章号、初登与已发生结果仍由[索引](章节索引.md)和[连续性表](连续性核对表.md)负责。本表安排从开篇重写，不从第101章突然追加能力，也不把规划中的场景记成已经发生。

## 开篇怎样兑现设定

第1章保留启元十一年深秋、宋35岁致仕与接差属官自己拟答的短引子，约二三百字便切入启元元年正月初一首次互换。致仕为何难与密旨内容继续留悬念，不先复述十年仕途。章内完成宋发现帝身、设法召见“自己”、私下确认燕在宋身，结尾落到她们必须出席的新岁朝会。

宋先拜、宁王同署、徐验真诏等放在第一次奏对所需的简短回顾里，说明此前争来的君权为何仍有人试探；必要处另用完整短场补足。先拜、验诏发生在结契之前，宋与燕当时都是本人，遗诏真实有效。丧父与政治逼迫有分量，不能把继位胜负改成魔法替打。

新岁礼制处于国丧中，不设庆宴、婚礼或热闹歌舞。首先写压下试探、让一项已批准的正常供粮命令得到执行；纳人议论、初夏看戏与秋日清丈按季节分别接起。

## 开篇15章场景安排

以下是重写时的拟议位置与章名，正式落稿后再改文件、索引和后文编号。同一日可跨数章，不能为了凑下一次互换跳过当日下午的后果。

| 拟议章位与章名 | 场景、争夺与回报 |
|---|---|
| 1・陛下，臣怎么在这里 | 短致仕钩子后切首次互换；宋先以为被抬错寝处，看到铜镜才知不对。私见顶着宋脸的燕，两个都想叫对方先解释，朝会却不能只让百官等着 |
| 2・你再说一遍 | 老臣以年轻女相越权为由，要加旧臣预署。宋在帝身被当面弹劾，燕在宋身险些先发作；借真实验诏与已批供粮的事实反制，让拖令者选承办而不能空称反对。宋不是趁帝身随意封赏自己 |
| 3・臣的父亲，今日要来 | 燕须回宋府接宋父来访。父亲教女儿守规矩，燕几乎习惯性等他行礼；宋在宫里发现一口点心也有人记偏好。酉初换回，两人各有一笔不愿认的生活麻烦，均未自动学会对方的本事 |
| 4・先把你答应的说完 | 两人核实今日答应了谁什么，查旧册得知月期和十二回。她们想少吃亏，议出最初几条界限，又为谁先写交代争起来；不写成长篇条款课 |
| 5・老夫这里不代劳 | 保温留旧课桌、桌底丑画与挤掉椅子的完整戏。宋本人争得顾命不再预署新君日常命令的支持，温也保住故生旧物与自己的立场，不只做帝相求解法的工具 |
| 6・别拿我儿子作保 | 保沈蘅与兄长的旧情、母子不随宁王和不替兄长担保。由宋本人会见，燕本人决定承诺；此场不靠互换偷听，也不作笑料 |
| 7・这回谁先出城 | 宗室各争年例护卫，肃王不愿陪宁王等，七皇子争先走。兄弟各有筹码；兑现依次就藩，宫中仍有家常，不能只留数份批文 |
| 8・你们平日就这么说朕 | 二月初一第二回互换，宋此前已与许姜梁约在女学相聚。燕照约前往，姜抱怨皇帝留宋太晚，许又问旧安排的漏洞。燕想为自己分说，越说越不像宋；梁顾自己的课，不陪她无限拖延 |
| 9・谁让你替我答应的 | 换回后，宋得知自己被应下算学答问，燕也发现宋替自己排了骑射问课；二人交代缘由、互相讨价还价，约好的事各自去做。朋友与受邀者有真实期待，不能一句作废便结束 |
| 10・青的也是杏 | 时间推进至初夏，四友本人看影戏、赌杏、逛布摊；姜梁另谈海与裙，宋许给许母挑梳。完整轻松章，不让皇帝借宋的脸包办所有旧友情分 |
| 11・画像先别收 | 夏末接政治择人。有人用家族出车与报田换先许婚；双方先争各想得到什么，女帝本人听条件并拒绝被画像代替。宋只谈承运和田税，不冒名替女帝选夫 |
| 12・想出去挑 | 入秋姐妹买头油，许主动请差却失约陪母看菊；宋宜只问租收分项。以本人生活和想出去办事的欲望带出平河差，不把亲情化成帝相观察题 |
| 13・这根丈绳，谁来牵 | 许到县受阻，县令依赖赵家工料，赵家握住佃约和水牛。点心与丢鞋先轻快，火灾伤人处收紧，许实报请缓。京中收到回文前不能提前知道险情 |
| 14・今日陛下也不肯撤 | 按实际日期安排秋月初一互换；陆要求撤许，宋在帝身不能只为朋友偏袒，燕在宋身也不能只拿君威压人。陆对催粮转嫁佃户的反问成立，二人补上办法，争得正式续查与协查支持；危险中的许不作笑谈 |
| 15・那个人，先让他出来 | 郑家借牛旧恩、分水受制与家内争执先成立，再写郑赴宴被留、谢求见。女帝本人核准救人；以会见或接人真正发生作阶段回报，赵认田、裁丁拆墙留下一完整段兑现，不在同章塞入所有平河结果 |

第14章所用初一须在地方时序中真实落到；若驿程与郑家事件不合，调整场景所占章数，不能把互换临时挪到火报抵京当天。前15章的主要变化是先让帝相、家人和朋友活起来，再推进平河，不再沿用“15章必须结清清丈”的硬节点。

## 16～100章的重排方向

| 拟议区间 | 主问题与所得 | 互换、喜剧和个人线 |
|---|---|---|
| 16～30 | 郑获释、各户自行递契、赵认田，协办得记功；齐韩本人应问、同定良人；九门点验争取原票，郑二本名实领 | 平河两地牵挂、陆家夫妻、韩家父子和姐妹夜戏保完整场景。互换让帝相看到同一旧臣两种态度，真胜利仍由许谢实勘、官署执行；元年腊月第十二回到期，双方各自考虑是否续契，新岁前夜再誓与否须在来春成礼之前交代 |
| 31～50 | 来春齐韩隔三日成礼、首批粮运交付，许归家领实差；北差现场拒担保作核明，虚报与货路只追一处关键矛盾 | 若新岁双方已自愿续契，入宫后第一次互换先写宋怎样守住相处界限、燕怎样亲自补约。许母、姜梁与宋宜有自己的进展。宫中男子可以不满，不能都在替宋掩饰 |
| 51～70 | 北差复命、原验揭虚报、退银补铁与恤银实领；父女赴约、宋宜亲自呈契 | 集中证据翻局，合并重复收报。许亲见换回后知情，有被瞒的不快，也有自己的条件；帝相承担此前答错朋友的事。宋拒私席是本人选择，不借女帝训父替代 |
| 71～100 | 地方退税安置、母子履诺与旧货销讫；驻峡救粮和分段换班逐步成为卷内大争夺 | 粮限和险桥保紧张，平时仍有宫中、家人与同窗喜剧。本段若处启元二年夏秋，须沿用新岁前已作的续契决定，不再误作第一契到期；每月互换可有略写，不漏算，也不每次都占数章 |

区间为场景容量目标，不是已发生事实的章号映射。若保留的完整场景使救粮换班后移，调整模块位置与卷内篇幅，不用急速报账把它硬塞回第100章。启元二年宋26岁、当前军政结果等仍按现有正文记录，重写到对应时间再核定新进度。

## 素材取舍与实施

- 保先拜、互押承诺、验真、郑出庄与赵认田、郑二本名、原验揭报足、银铁实到、母子承诺、旧债清偿与旧班退换。压缩一件事多轮追件、转呈与重复解释；保真动机、反击和赢后回报。
- 旧生活戏按当时本人出场接续。必要时让互换挤坏原本的约，随后由本人补偿；不是把原来每一场的宋都换成燕。姜梁可独自往来，许母自行买花，宋宜自己经营。
- 宋与燕都要有主动欲望、失算和本事。帝身带来的发令便利必须有本人授权与承办条件，宋身带来的亲近也会碰到朋友和家人不肯说的事。对手能利用字迹与习惯试探，不能看到帝相亲近便立刻断言妖术。
- 一回互换至少在处境、关系或打法上有新变化；准备得越来越好后，麻烦来自利益与选择，少重复认不出人、穿错衣、说错称谓。未互换时也必须好笑、好看、有输赢。
- 正式重写按完整场景分批推进，在原文件上替换、必要时统一更名重排，只留一套正文。每批同步实际索引、两组模块、连续性和初登；宋父等提前出场后须删除后文的重复初登介绍；未重写部分仍按真实内容登记，不提前给其套上新章名或互换次数。
