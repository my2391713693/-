# 帝相互换设定

## 核心承诺

宋宛替燕昭宁争来了皇位，随后发现自己每月还得替她当一天皇帝；燕昭宁也得用宋宛的身份，去见那个敢训女相的父亲、听同窗抱怨皇帝、替属官收拾难题。两人都觉得对方占了自己的便宜，偏又得一起把这一天过完。

架空古代，两人均为本世成长的女子。唯一超常设定为帝相定期互换身体，不叠加读心、看见欲望、穿越、重生、系统、预知或其他可调用法术。朝政、婚姻和军务仍按人的本事、利益与制度运行。前30章已落实首次相认、规则查明、女学代班、第一契到期与除夕自愿续契，实际次数和知情范围查[连续性表](连续性核对表.md)。

## 来由与固定规则

| 项目 | 作者确定的规则 |
|---|---|
| 器物与来由 | 御府保存一对开国旧玉，名为同劳玦，原属停用已久的君臣共誓旧礼，先帝未行此礼。启元元年正月初一前夜，两人商议怎样抵住旧臣要求额外预署新君命令的主张，翻到开国君臣共同担责的旧仪，决定以共誓互相作保。她们各执一玦，各自应下“愿以一日，代彼之劳”。她们以为只是结盟誓辞，翌晨应验。旧礼的完整附记可在御府旧册查到，前几章便查清，不以长期找秘术另开主线。先帝遗诏与宋的先拜均发生在结契之前，不受玉玦操纵 |
| 首次发生 | 启元元年正月初一卯初。宋的意识进入燕昭宁身体，燕的意识进入宋宛身体；此时两具身体各在本人的居所，交换不需要在同一处 |
| 周期与时长 | 每个农历月初一卯初互换，酉初自动换回，共六个时辰。以燕京计时为准；闰月不增加一回。每次只有这一整段，不因剧情需要忽早忽晚 |
| 是否可控 | 不能临时发动、提前结束、追加时辰或单方拒换。佩戴、摘下、藏起、损坏玉玦均不改变已生效的契约；它是立契物，不是远程开关。后来可预排当天行程、练习和授权，但准备仍可能遇到人的变卦与突发事件 |
| 契约期限 | 一契十二回，第十二回酉初换回后自动终止。若想继续，须在下一正月初一前夜重新合玦、双方自愿再誓，才续十二回。首次误结之后不增加隐秘罚则，不以皇命逼另一方续契；每次续契都应有双方想要的所得与愿承的代价 |
| 换的是什么 | 意识和各自已有记忆换过去，身体留在原地。外貌、声带、体力、伤病和衣物属于身体；语气、惯用词、学识、字迹习惯、口味偏好属于本人。宋不能凭女帝的身体学会骑射，燕不能凭宋的手写出宋原来的账目；熟悉身体可改善动作，不能白得技能 |
| 信息边界 | 没有共享记忆、心声、视野与感觉，也不能隔空传话。对方没告知的人名、私事和办差经过仍不知道。书信、传话、见面皆有正常时地限制；异地互换也不传送人、物、粮款或军令 |
| 伤病与危险 | 受伤、疲倦和药效留在受影响的身体，换回不治伤、不解除下毒。换回时意识回到自己本体所在处，不能任选落点。昏睡不延时；本体死亡者不能借对方身体续命，不使用杀身换回、替身复活等漏洞 |
| 正文揭示 | 首次只呈现发生与应对，酉初换回证实第一条规律；随后查旧册说明月期与十二回。叙述者掌握上述规则，人物在查明前只能猜，不能凭直觉知道准确时辰和解法 |

玉玦只解释这一个奇异现象，不会鉴忠奸、指认真诏、召兵、示警或分辨谁在说谎。旧礼没有选择“天命女帝”，两位女子的成就仍由自己挣来；对手也没有一套对抗法术。

## 读者怎样始终认得人

叙述中的“宋宛”“燕昭宁”始终指意识本人。转场首句写清谁在谁的身体里，例如“宋宛坐在御座上，用的是燕昭宁的脸”。随后用本名叙述，不连写两个含混的“她”。外人对白按眼前身份称陛下、宋相，外人判断也按其所能见到的行为成立。

互换瞬间两人各短暂失神，外形没有变化，旁人看不见魂魄出入。不能只写许在旁边看了一眼，便称她亲眼看见了真相。

进入下一场、跨日或换回后补必要定位。每次开写先在连续性表登记日期、起止时辰、两具身体所在处、各自手里物件与消息；同一具身体不能同时出现在宫里和宋府。衣服、钱袋、伤处、信件不会随意识换走。

## 她们先要守住的界限

- **大事须本人决定。** 婚姻、亲密关系、杀人定罪、废立、重大任免和调兵不得替对方擅定。日常奏对、接件与已定事务可事先授权；当场出了新条件，要争取会面、递话或延后裁定，不能每次都借“身体不适”搪塞。
- **紧急时先护人。** 火灾、袭击等当下危险先依既有职权救人，事后如实告知；不能把一切政治分歧都包装成紧急例外。宋即便用了女帝身体，也不凭空掌握军情、认识将领或获得统兵本事。
- **名声与责任不能换走。** 对外的话由公众看见的身份承担，私下须完整交代自己答应了什么。未经同意替对方揽差、得罪熟人，换回后会有补救与争执；严重伤害不按一句笑话销账。
- **生活可帮忙，不能接管。** 不偷读无关私信、翻查身体隐私、替人订亲或许诺情爱；必要起居简洁带过。女帝不能因知道宋家难处便包办父女和解，宋也不能替女帝裁定喜欢谁。

## 人物关系如何持续生戏

| 关系 | 初期各自的不服 | 后续要争、要付出的东西 |
|---|---|---|
| 帝相本人 | 宋觉得皇帝一句话就能办，燕觉得女相有自己的宅院朋友、能出宫便能歇 | 宋发现每个小偏好都有人揣摩，燕发现属官、父亲与朋友也各有所求。认识处境后仍不自动同意对方的做法；合作要重新谈时辰、授权、谁收尾 |
| 宋家 | 父亲认眼前人是女儿，照旧教她守规矩；女帝听惯臣礼，一时不知该怎么接 | 喜剧落在两套习惯碰撞。她可为宋挡一次失礼要求，却不能用天威逼父亲爱女儿；宋的委屈与父女变化仍由宋亲自面对 |
| 女学旧友 | 姜向“宋宛”抱怨皇帝留人太晚；许让“宋宛”自己算她安排的路日；梁不肯为朋友临时挪课 | 皇帝须听朋友真实的不满，还不能当场按君臣论。宋会因女帝替自己答了朋友的事而恼火；朋友依自己的目标行动，不能专供套话 |
| 齐韩与宫中人 | 宋第一次以帝身面对政治择人，怕一句随口应答成为许婚；齐韩也会察觉皇帝时而疏远 | 政治合作照谈，是否亲近由燕本人决定。宋可以暂避私下相处、照已约事项传达，不能冒名接受爱意。齐韩会为失约、不被告知或被当成家族条件而生气 |
| 旧臣与下属 | 同一个人面对皇帝与年轻女相，规矩、勇气和客气程度不一样 | 让读者当场看见差别；人物面对新说法也会试探、验证和反击。互换带来的见闻只是线索，公开争夺仍要证据、联盟和实际执行 |

前30章只有宋、燕明确知道真相；许等可因字迹、习惯与遗忘起疑，但不凭一句口误断定换魂。中段许在酉初前后同场看见两人的习惯与说话承接同时改变，追问后由两人告知；再以刚才各自单独听过的私话和字迹核实记忆确随本人到了另一具身体，而非看见魂魄。她接受解释也基于对宋的旧信任。不让她立刻变成替二人圆谎的随从：她先要问朋友为何瞒自己、以后哪些差事还能算本人答应。其他人是否知情须另有亲见、决定和代价，不默认全员默契。

已写的三日骑射与三日算学答问，来自二人都觉得对方本来就会，擅自答应后仍须本人收尾。后续仍可有不伤根本、又确实烦人的日常约。彼此都觉得“也没什么”，直到轮到自己去。玩笑要有对方回嘴与实际收尾，不能发展成拿性命、婚事或官位相互报复。

## 长线与退出

前段从不情愿代班、互相补漏到主动准备；中段开始有计划地利用不同身份打破一处僵局，同时承担被看穿、滥用对方信任和自己判断错误的代价。大部分月份用简短交接带过，只把有新关系、新选择或新胜负的一回写成完整戏。

第一契已在23章十二月朔酉初终止，24章除夕双方在能停止的情况下自愿再誓十二回，第二契写至二年五月第5回。此后每到第十二回，仍由双方分别决定是否续契。愿意继续也不代表放弃私人生活，更不证明她们必然相爱。宋与燕仍为君臣旧交，感情类型不预定，齐韩现有关系不被抹掉。

故事从首次互换顺叙，后续去留随人物选择与实际局势发展，不预定宋在某一岁退休，也不预埋必须兑现的密旨结局。若发生官职转任或离任，须写清接替与正式安排；若涉及军务，互换不替代训练、经验与正式授令。每年契约都有明确终期，结尾不能靠“永远换不回”强留宋，也不能把病、死亡或爱情设为魔法唯一解法。
