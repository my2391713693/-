# 整体大纲

全书核心：年轻女相宋宛扶燕昭宁登基，随后与女帝每月互换一天身体。两人一边替对方维持体面，一边发现自己原先想得太容易；从抢着定规矩、互相惹麻烦，到能联手反制旧势力，仍各有私心、朋友和去处。轻松喜剧为主调，胜负明确，真正的危险才收紧语气。

宋想凭本事赢、护自己选的人，也想有一天不必因谁离不开她而留下；燕想让皇命执行、不再被当作替代的皇子，也想身边人主动选择自己。互换让这两种愿望撞得更近，不替她们消除分歧。她们既会借对方的身份争一口气，也必须替自己造成的麻烦收尾。

架空古代，宋、燕均为本世成长的人物。唯一超常现象及其来由、期限、能力与权限边界见[帝相互换设定](帝相互换设定.md)。女帝纳人、女学旧友与旧臣争权继续构成长线；不加入读心、看见欲望或其他外挂，也不把查案改成靠换身偷听一切。

## 阅读承诺与开篇

第1章直接从启元元年正月初一第一次互换写起：宋宛醒来，发现床、衣裳和镜中的脸都不属于自己，随后与顶着自己面孔的女帝在宫中相认。第一轮即写宋坐在御座上听人弹劾自己、燕顶着宋的脸难忍回嘴、下午又得去应付宋父。酉初换回后仍有答应过的事要办，喜剧连续产生实际后果。

永熙三十年腊月的真诏、宋先拜、宁王同署与百官行礼，是互换之前已经挣来的胜利，用第一次朝会所需的回顾恢复因果。丧父的分量不作笑料；继位真实、人物本事与主动选择不因奇异设定失效。新岁仍处国丧，正常奏事与庆宴分开。

前15章实际结构与后续场景容量见[重构规划](前100章重构规划.md)。实际文件为第1卷《拜见新君》1～100章，1～15已写入互换；正文事实见[索引](章节索引.md)与[连续性表](连续性核对表.md)，不能将下面的拟议阶段当成已写结果。

## 第一卷《拜见新君》

本卷约150章，以“这位女帝的话怎样真正有人执行，这两个人怎样在互换中仍保住各自的选择”为持续主轴。以身份事故打开故事，继位余波、宗室与朋友家人先把人物立住，再接平河清丈、政治纳人、九门核饷与驻峡争夺。事件段不单独开短卷。

| 阶段 | 政治争夺与可见回报 | 帝相与群像的推进 |
|---|---|---|
| 先过完对方的一天 | 旧臣想借预署架住新君，帝相以真实名分与已批事项争得执行；宗室各领所需离京 | 首次互换上朝和见父；第一次换回还要兑现承诺。温的课桌、沈母子选择与朋友的课和饭约各有自己的意义 |
| 谁肯站出来 | 清丈受阻，郑家被借牛旧情与分水控制牵住；救人、各户自报、赵认田、裁丁拆墙落实，功归许谢等实办者 | 宋保朋友却须补上旧方案的缺处，燕不能替她以皇命解决全部人情。姐妹挑香、许母买花、国公夫妇生活并行，胜利后能吃饭看戏 |
| 人不是一幅画像 | 女帝政治纳人，家族争承运、位分与便利；齐韩亲口选择，首粮实交，六新丁用本名领饷 | 宫中人有自己的期待。元年腊月先写契约到期与双方是否自愿续契，来春再接成礼。宋在帝身时不能代定喜欢或婚约；燕本人经营婚后相处。许争到自己的差职和休息，不因旧友亲近而被包办 |
| 换个位置，也得认账 | 北差、虚报、旧卒与地方税田围绕一个关键争点一轮兑现，退银补料、恤银、田契和承诺到手 | 帝相开始有计划地合作，也会拿错信息、互相护短。许亲见换回后知情，朋友关系先受冲击再重谈；宋本人面对父女旧伤，宋宜自己经营 |
| 该由谁付代价 | 缺粮与换班把京中、军府和商户拉到同一争夺；守兵吃上粮、商户拿回钱、越权者失便利，京中拖延同样担责 | 互换遵守跨年前已作的契期决定。宋想学军务，燕既要能接差的人又不愿放人；熟人日常和宫中亲近在紧张间隙继续生长 |
| 合作能不能让人自由 | 驻防方案在粮、人、守段和接替之间取舍，正式命令经过实际执行；官署能接事，帝相不靠时时互换才能办成 | 卷末给一次主动联手的大胜，也保留对去留的不同愿望。宋仍须凭训练与正式授令获得军务资格，不能把女帝身体当成统兵本事 |

各段可随完整场景调整篇幅，日期随正式重写核定。每月只有一天互换，其余时间仍是她们本人争权、交友、过日子；每回不必全写，但不能漏掉固定月期。新章位不替代现有文件编号。

## 持续人物线

| 关系或人物 | 持续要什么 | 怎么使故事继续变化 |
|---|---|---|
| 宋与燕 | 一个要凭本事赢与选择去处，一个要握住执行权与被主动选择 | 从互相嫌弃到信任加深，再面对同意合作也未必同意去留；关系不预定为爱情 |
| 许明砚 | 实绩、署名、独立决定和能守住的归期 | 能受宋保护，也能拒绝宋；知情后有自己的条件，不能变为帝相的备用圆谎人 |
| 姜令仪与梁素 | 姜要仕途、远行与自己的婚姻，梁要教学、家人与自己的时辰 | 旧友互相羡慕，也会不体谅；她们在宋不在时仍有往来，不因女帝听过抱怨便被整治 |
| 宋宜与宋父 | 姐姐要经营自主，父亲想关心又放不下旧序 | 帝身或宋身的一次撑腰不能解决家庭关系；由本人赴约、持契、经营与回嘴逐渐改变 |
| 齐绍与韩知微 | 各自亲近女帝、保有家庭与个人愿望，家族又要从合作中获利 | 愿入宫不等于愿被别人替女帝答话；宫中日常、家书与失约产生真实的亲疏变化 |
| 旧臣、军将与地方人 | 保威望、秩序、便利、家族与旧恩，同时也会真为公事着急 | 能反驳宋、识破疏漏、拒绝条件，也能为合作得利；不把阻力统一解释为反女帝或幕后谋反 |

个人生活可完整成章，结束于闲闹、相聚或没说开的心事。人物不必人人悲惨，不轮流给宋讲道理。具体接续见[个人情节规划](人物关系与个人情节规划.md)，固定身份不因互换改变。

## 后续长卷与远期收束

后续随舞台扩大，以地方执行、军政经验、外部争夺及朝中接替形成足以支撑长卷的任务。互换会带来异地消息差、代理权与信任的真难题，也给帝相看到不同的人和不同的生活的机会；不靠扩大魔法权限推动升级。一个大胜换来新的选择、盟友与可用条件，不能永远只多拿一份原件。

宋婚事在后段去留与利益冲突中才启动，按双方本人的意愿推进；既有齐韩婚姻不被换身抹去。若宋此后争取军务转任，须建立训练、京中接替、粮饷和正式授令，不能靠帝身直接跳过。

故事按当下情节推进，不预定退休年岁或必须接回的结局。各人的官职、去留与关系由持续选择积累，当年互换契约仍有明确终期；燕想留人，也须容许对方选择。关系回报来自自由情况下的相聚与合作，不能以永久换身、不可解诅咒或不续契就死逼她们留下。
