1～15章已按[帝相互换设定](../帝相互换设定.md)落稿；后续仍按实际正文登记，重排方向见[重构规划](../前100章重构规划.md)。索引负责逐章入口，连续性表负责日期、互换次数与物件，以下只记场景任务及交接。

| 区间 | 已写任务 | 转折与交接 |
|---|---|---|

| 5～7 | 温搬旧桌、拆顾命预署，宗正存贺旧信；沈母子自行选去处，宋本人回家吃饭与复奏；三府各领实需依次启程 | 旧臣具体疑问仍可提，不以顾命副署卡新君；沈只许母子、不保兄长，十一原话已带；护送与多领军械各办，宁肃七不再共同拖延 |
| 8～9 | 二月朔燕替宋赴女学，听朋友抱怨、路日反问，双方各替对方接三日差；换回后本人履约 | 许姜梁各有课、约与牵挂；宋与燕不转技能，算学答问和骑射真付时辰，各有所得与窘处，宋答应另约无账无课的相聚 |

| 13～15 | 平河候册受阻、火后实报；九月朔帝相共同保续差、补税法，访母家信与国公家常并行；谢先见本人救郑、各户自报、赵认田 | 初十郑已获释，国公十五日的亲眷旧闻不能替有司事实；协办记功不归赵。赵首批裁丁拆墙已行，余项与刑案各续，许留县，二十七日姐妹夜戏收束 |
| 16～18 | 七幅同脸画像与运租样页接政治择人，韩家父子抢话、添盐与留饭，齐韩各自应问 | 齐侯争新朝门路、齐绍求独自被听；不以许婚换报田出车。侯府实议车脚、入冬落约；韩父护儿、女帝拒门第定正，同定良人待来春隔三日成礼，齐绍自己领须知，秦武夜查旧名实领 |
| 19～21 | 军门拖票、三署分班点验，方管事代传求缓 | 秦反驳问时与伤恤、要求自查，宋改真难处仍争到原票同核；拒以补押旧月换饭饷，六名新丁本次验明本人领，郑二换本名点牌并实领；宋退礼，不准侯府以运粮求缓军票 |
| 22～24 | 侯府交粮、齐韩成礼，许归家休息后领实差 | 解除齐世子号、次子承袭奏稿另件呈请未准，拒侯府以首批出力包后批；齐谢凳、晚膳各挑菜与选错闲书，许母收走算题、看印又想向邻人夸女儿，留完整场景；女帝认准换防仍不替缺续件结案；许拒吞已准歇日，接件司官另得抄件协助，面对等缺同僚争到正式接案、接件处与限期借人 |
| 25～30 | 具体里段推进清丈，许首赴北差，宋查旧款与货路 | 廊下改稿连砚台也须跟着躲风，检车试靴时宋只买毡却险些买鞋、母亲送行后看花；全州停办未准、已量先报，本部补费也定日期；许先宣御赏促当天开仓，犒粮三册核齐，另粮欠票获准续核半月；拒主帅担保替已核、拒新差换缓旧款、拒付款替实收结销；贺宴与京中采买交锋，旧友半日试裙越帮越忙、吃糕算题，姜自己拟请调，纸又贴上宋袖；约次晨访德顺、陆献图求仕待会见 |
| 31～41 | 京晋旧货查访与陆本人献图，邱取回本名、宋宜准备呈契 | 杜顾生计、邵只认京晋；北屯实入却欠批准，许带两箱返京并坚持实查署名；柳林双税缓催 |
| 42～50 | 姐姐夫妻呈契、父女按约相见；核图、接差、原柜会验与同窗相聚 | 陆认错仍求请阅；宋补接办并拆开错夹清单，原验早四日揭报足；96实用退4入库，图准还，缺料与问责交后段 |

择人交接：九月二十七日平河初报京收、姐妹夜戏；二十八日16章画像到府、宋宜带样页再来，二十九日齐家父子入见，三十日17章访韩。16章齐绍亲答愿入宫，女帝尚未许婚；侯府愿报田、自费承运京南官粮入京供守军，候渡与改仓费用先议明，户部核车马后落约。17章接韩家父子答话；18章入冬收册落约、分别召见，数日后朝上同定良人，方守成接粮运、齐绍亲领须知，入夜秦武追旧册中六名新丁的实领。22章侯府首批实交，齐绍同夜转家信、自选闲书；23章韩成礼，许交册挑笔、歇满一日，24章领印及接替。26章检车后两日启程，27章十二日抵营、首报四日到京；28章贺于抵营第八日归来，续核半月自领到准函起算。29章姜仅拟请调、尚未向本部递呈；30章上午约德顺，午后奉准，回文交差役次晨北送，查访也自次晨起算。粮源、去向与费用边界见[连续性表](../连续性核对表.md)。
