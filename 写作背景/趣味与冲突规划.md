# 趣味与冲突规划

基调为朝堂群像喜剧：年轻女帝争能执行的君权，好胜女相与一群各有本事、各有所求的人拆招，也逐渐学会一起过日子。长线以宋建立接替、肯交相印回应盛年致仕的开篇。

## 趣味从哪里来

| 来源 | 场景方向 | 关系变化 |
|---|---|---|
| 本事各有所长 | 宋问账逼住秦，秦用接班路问住宋 | 互相不服，也逐渐承认对方有用 |
| 体面撞上日常 | 宋赴约晚到，朋友先吃但仍给她留菜 | 朋友有自己的时辰，关心仍在 |
| 便宜连着责任 | 侯府争承运，却要自己出车交粮 | 合作有所得，也有劳动和成本 |
| 熟人看破嘴硬 | 宋说顺路，姐姐给她端常吃的菜 | 从不肯直说，到能约定相聚 |
| 自己也受办法约束 | 宋催各署说难处，许先退她没算车修的日程 | 宋须调整行动，配角有实际所得 |

笑点展开有头有尾的交锋，落在动作、短答或沉默里。丧亲、伤病和危险保留分量，轻松由准备、照顾与成果恢复。人物的欲望和组合见[个人情节规划](人物关系与个人情节规划.md)，写法见[写作规范](写作规范.md)。

## 全卷节奏：拟议安排

| 区间 | 主事件与回报 |
|---|---|
| 1～7 | 先拜、验诏、就藩；熟人拆招与母子夜戏建立轻重两种声音 |
| 8～15 | 军需引清丈；庄门打开、人获释，首政有可见成果 |
| 16～25 | 政治纳人、成礼与相处；合作兑现，外家要求带来新难题 |
| 26～40 | 实名、找经手、揭虚报；宋与秦各赢一轮，朋友和家人逐渐熟悉 |
| 41～50 | 补料、补偿与处分执行；前段的饭约、家事和个人愿望得到回应 |
| 51～65 | 旧货与地方余责收束，逐渐形成独立承办与接替 |
| 66～85 | 北差、粮限、险桥和救粮；危险集中，粮到后有喘息 |
| 86～100 | 清旧偿、追两端责任、实际换班、归家；积累明亮的阶段回报 |
| 101～120 | 定驻防、学军务、争去留；约110章后才考虑宋婚事的新压力 |
| 121～150 | 任用与接替经受考验，各人选择产生代价，卷末兑现独立执行的成果 |

每段集中一个眼前问题，重要胜利现场展开；人物生活提前铺垫，后段兑现。这里安排情节容量，正式改写顺序见[前100章重构规划](前100章重构规划.md)，婚姻调整见[婚姻线分布](婚姻线分布.md)。

可延续三种生活回声：赴约迟到到主动留饭；借口顺路到明确约时辰；纸上安排到亲走接班路。每次随人物和结果变化，避免固定包袱。
