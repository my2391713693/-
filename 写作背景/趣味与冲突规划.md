# 趣味与冲突规划

全书以轻松喜剧为常态，叙述、日常朝事与人物相处均有乐趣；强对抗和鲜明胜负在这个基调中展开。真正的继位危机、人身威胁、火灾和伤亡收紧语气，安全后自然恢复轻快。普通念旧和牵挂可以温暖，不习惯性转成伤怀。

核心笑剧来自帝相每月互换一天身体。两人自己陷入不愿处理的场合、想占一点对方便宜、怕露馅又要争一口气，旁人也各有打算；读者看得见她们怎样越补越麻烦。固定规则只由[帝相互换设定](帝相互换设定.md)维护，章位与速度只由[重构规划](前100章重构规划.md)安排。前15章已落实首次上朝、停俸之争、见父、核桃糕、女学摆碟当渡口与互添三日差；下文其余场景为设计用法，是否发生查实际正文，不把可用笑料都记作既成事实。

## 喜剧要有连续动作

从一个具体欲望开始：宋想保住俸禄、买自己满意的书案，燕想让朋友替自己说句公道话，又不愿照宋的交代处处受管，许想把等人的半日拿回来，齐绍想吃自己挑的菜。先让人物应对，再让应对带出新麻烦，旁人接招，最后回收开头的打算。笑点不能总是两句机锋后“大家笑了”，也不能把所有小玩笑都升成一次人格教育。

| 来源 | 可以连续展开的场景 | 后果与边界 |
|---|---|---|
| 身份越高，越不好说实话 | 宋用帝身多吃一口不喜欢的点心，只为尽快吃完散席；宫人却以为圣意喜欢，下一餐又送来。她想说不爱吃，又怕让做点心的人无故受责 | 自己解释、改安排，不能处罚无辜宫人收尾；偏好怎样被误记须由具体动作造成 |
| 熟人面前，君威使不上 | 燕顶着宋脸想为“皇帝并没留人太晚”分辩，姜逐项报她误过的饭约，许再补自己等到几时。梁要按时上课，请她们边走边说 | 燕不能以不敬论罪；朋友也非全知，抱怨有公开经历与自己的不便 |
| 想替人解围，先把自己放进去 | 朝臣弹劾宋，御座上的宋想平稳结束，下面的燕却先回敬；宋不得不把话接回具体差事，又怕自己护自己过分明显 | 用一项真实争点反制，赢在执行；不为逗笑将守丧、定罪和人命当儿戏 |
| 对方的时间，答应起来最爽快 | 宋替燕应了骑射时辰，燕替宋接算学答问，二人换回才发现自己多了事；准备时各来问对方“你平时不是说不难” | 当事人有拒绝新要求的权，也须处理已给旁人的期待；不能拿婚姻、官位和性命作报复 |
| 宋家不是朝会 | 宋父教眼前“女儿”规矩，燕惯性等臣礼，父亲也等女儿认错，两个人各自把茶端起来，谁都不先说下半句 | 父亲有真实旧观念，燕也会接错；别写成女帝训父一次，宋的童年委屈便结清 |
| 想准备周全，没准备到人会变卦 | 帝相备好当日名单与问答，一个原本不来的熟人忽然到了。宋记住的是官衔，来客却先问上次送的东西好不好用 | 熟人能察觉不对、继续追问；不能每次来个宫人把答案喊出来，交代纸也不能等同共享记忆 |
| 熟人本人同样会出糗 | 宋试香抹多、分饼比大小，许赖青杏反酸牙，姜帮试裙越帮越乱，温护旧桌挤掉自己的椅子 | 未互换时也好笑。她们的习性和小私心提供日常乐趣，不都变成揭身份的线索 |

递进来自人做了什么、别人怎样回应。叙述可用当事人嘴硬、偏心的眼光，不以公文结论压掉趣味。专业本事不能每逢笑点就消失；宋不认宫中熟人是记忆不共享，算错自己熟悉的简单账则须另有当场缘由。

## 互换如何变化

1. **第一次：先过完今天。** 不知道多久能回，朝会和父亲都在等；各有本事，也各露一处不熟。换回后留下明天真要办的事。
2. **知道规则：争谁来收尾。** 会准备，也会把自己觉得简单的差事交给对方；麻烦来自不同习惯和不同看法，不能循环认不出人。
3. **开始配合：主动反制。** 同一人对皇帝与女相口风不同，双方将已知条件放在一起设法破局。见闻仍须核明，真正回报是拿回东西、保住人、让命令执行。
4. **关系更近：隐瞒也有代价。** 朋友、家人和宫中人不只是看她们演戏；忘了私约、冒然答应、亲疏异常会使人不快，须由本人面对，不能每次都以真相不可说为免责。
5. **到期：能结束，才谈继续。** 两人分别想清继续互换对自己有何所得，又愿让出什么。续不续都不以忠心、爱情或对方生死相逼。

这不是每回固定走一遍的模板。多数月份可短写准备或换回，只展开对人物与局面有新东西的一回。没有互换的日子仍要有好笑的生活和主动的政治交锋，不能等到初一才像小说开始。

## 人物先有不肯让的东西

宋能在朝上认自己没想全，也会在私下记着国公得意的神情；她替朋友争署名，自己也享受被人依赖，书案不肯多付两百文，点心却要专添一个抽屉。燕肯替宋回家，会在训话前先替自己辩，见抄书的工夫又不能只顾反驳；她想亲自听荐婚者说话，也不喜欢宋总先替自己挑过。相处中的好意、冒犯与亲疏同时发生，不用一句互相理解便抹平。

许要独立成事，真写未量也会怕丢脸；她不喜御史叫自己回避，见谢同样追问县令，才换一壶热茶。梁想买自己的裙，拒朋友付钱，不必把购买写成众人劝她终于想通。许母盼女儿回家，又怕自己一叫，女儿日后不甘。郑记旧恩也省过隐田税，肯报以后仍想把最后一张契藏一藏。人物的矛盾既由举动显露，也让读者听见本人没说出口的心思：她想听谁夸、怎样替自己辩、明知理亏又为什么不肯先让。内心用本人当下的口吻，不替她总结性格；好笑的念头可以只是偏心、得意或怕丢脸，不必总导向悔悟。

机关不是每章各配一个笑料。要看一个小打算怎样被熟人看穿、反过来卡住本人，争完仍会迁怒、偏心、心疼或得意；嘴上不认，动作已换了一点，关系便有后续。

## 立场先有生活依托

郑家报田来自借牛旧恩、求水受制、父子对添仓与租牛的不同打算；堂弟欠种粮，不愿跟报。齐侯出车要向各房交代，韩父护儿也不愿借旧部作押，陆靖替妻家说话又要保旧族能与朝廷商量的位置。人物在作选择前把这些来由显出来，别等主角报功时才补一句。

女帝换进宋家，也不能只得出“庶女可怜”；她可能羡慕宋能和姐妹逛街，宋又可能觉得皇帝一句拒绝便能散席。两人看到的是自己站到的位置，还会看错。亲近与认识增加，并不自动统一立场。

姜想远行、梁想新裙和自己的课，许母要看花，宋宜想与妹妹出门。这些愿望独立成立，可以完整成章与安静收尾，不负责替帝相提供消息、解法或教训。具体人物进展见[个人情节规划](人物关系与个人情节规划.md)。

## 每轮冲突要有手段和所得

先写清谁想要什么、对方为什么不肯、失败失去哪项具体利益。对手可以扣东西、争预署、抬交换条件、找替代人选或争取旁人；宋与燕也要主动试、付代价、借分歧反制。互换只能改变接触位置和当场处境，不能让对手突然愚蠢、证据自己出现或朝臣认出“这是女相所以更厉害”。

| 爽点 | 可见的现场结果 | 互换可参与到哪里 |
|---|---|---|
| 反将一军 | 对手提的条件也约束本人，不得再只索便利 | 宋在帝身听到另一套说辞后，燕本人拿真实矛盾要求履约；不能拿秘密见闻直接定罪 |
| 当众护短 | 郑二用本名领饷、许保实差与署名、郑真出庄 | 可以替伙伴争机会，现场成果仍由本人取到，不把配角功劳改成帝相显能 |
| 拿到实权 | 皇命有人接、粮有人运、官署不再等旧臣额外预署 | 两种身份协作争破一处阻碍，正式决定仍有燕的授权和正常执行 |
| 能力翻局 | 原验揭虚报、秦反证一处军事误判，随后各交该交的部分 | 不能互换记忆补技术，宋与燕都可被有效问住，再靠自己的办法争回所得 |
| 生活得偿 | 看完整场戏、歇满一天、挑到喜欢的衣物，约好的人真来了 | 亲近本人兑现，不能都由代班人取代；赢后留余味，不立刻补一份缺件单 |
| 赢回选择 | 能自己定差事、经营与婚姻，接替者办得成，契约到期可以结束 | 自愿续契才有关系分量；不以永久换身束缚人物作为圆满 |

连续受阻两三章后检查有没有主动变化或一场小胜；大事件收束要有实物、实权、名分或选择的回报。问住、签名与催件是手段，不是所有胜利。对手败一轮仍有可用本事与牵挂，才能继续交手。

## 节奏与收口

开篇先兑现身体互换的场面，继位前因短而有力；宗室亲缘和女学朋友接起人物生活，平河、纳人、核饷再依季节展开。不同事务围绕一个眼前主问题安排，先说为何急，再给数字；不能因想在一回互换里塞满爽点，省掉驿程和执行。

每段危机有结果后，让喜剧自然回来：当事人抢饭、嘴硬、互算谁多干了事、终于赴上自己的约。火灾伤者、饥饿守兵、被强留者和沈母子不承担羞辱性笑料。少用宣判、感悟和空泛反思收尾，落到人物实际做的事或尚未答完的话。
