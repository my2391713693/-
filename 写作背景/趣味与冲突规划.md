# 《女帝登基：满朝不服，我先拜》轻松喜剧方向规划

正文1～15章采用本文件的朝堂群像喜剧方向；下文负责全卷人物组合与后续情节设计。人物现况与已发生事实仍见[连续性表](连续性核对表.md)；前段实施见[前100章重构规划](前100章重构规划.md)。下文的章节区间是情节容量建议，不表示其余正文已经照表调整或重新编号。

## 一、故事的新承诺

一位年轻女帝登基，满朝各有不服；一位好胜的女相先拜了她，从此既要赢过朝堂上的老狐狸，又要学会和这些人一起把日子过下去。

主类型拟定为朝堂群像轻喜剧，以权谋胜负带动故事，以熟人相处积累感情。读者应期待宋宛下一次怎样拆招，也期待她得意之后会被谁说得接不上话。许、温、秦、女帝都能赢她一场，胜负由各人的本事和所求决定。

长线仍是宋帮女帝取得能执行的权力，逐渐建立能独立办事的人，最终敢交出相印。喜剧气质来自她的矛盾：她希望天下事都办妥，好回家吃一顿安稳饭；别人真能自行办妥，她又忍不住凑过去看。三十五岁告老的开篇因此既有荒诞感，又留下她为何终于肯放手的悬念。她当前仍好胜、想证明自己，不能从开头就写成一心逃差。

建议简介的轻喜剧语气示意：

> 父亲送宋宛去女学，只盼她别惹事。她答应得很好，后来连中三元，做了左相，还在满朝不肯拜的时候，先拜出了一个女帝。
>
> 朝堂上的大人们原想教她规矩，渐渐发现，这位左相记性太好，客气话最好少说。
>
> 宋宛也有怕的人：敢把她晾在饭桌边的同窗，敢退她初拟的老将，以及那位总能在她告辞前再问一句的女帝。

正式简介见[简介](../简介.md)，以人物窘处与直接交锋呈现喜剧语气。

## 二、笑点由什么持续产生

| 喜剧来源 | 具体场景 | 谁得到或失去什么 |
|---|---|---|
| 想赢的人碰上另一位想赢的人 | 宋准备好一场辩论，秦却带她走一段真正的接班路；她不肯服软，走到半程先找阴凉 | 秦赢在经验，宋得到自己欠缺的判断；以后能用学会的条件反驳他 |
| 身份体面与日常欲望碰撞 | 宋郑重赴同窗饭约，朋友已经吃了，给她留的菜还在；她想摆左相的架子，却先饿得没话说 | 朋友拿回相聚的时辰，宋仍得到一顿有人为她留的饭 |
| 各方都想占便宜，条件却连着责任 | 侯府想取得承运机会，又嫌实地送粮麻烦；女帝愿给公平争取的机会，侯府自己要选拿名声还是走这一程 | 宫中合作有具体兑现，侯府既有所得也付劳动和成本 |
| 熟人知道她没有说出口的话 | 宋说自己只是顺路，宋宜把她常吃的那一碟端出来，也不拆穿；下一次宋宜忙着收麦，让她等 | 关心有来回，姐姐拥有自己的生活，妹妹的身份不保证优先 |
| 自己安排的事反过来约束自己 | 宋嫌别署拖延，提议各自当面说难处；许首先指出她的初拟没有算车修和行程 | 办法仍有效，宋须先接受自己也在被问的人里 |

喜剧场景要有完整变化：有人想省一步、保住面子或讨一点便宜，对方偏不按预想来，双方加码，最后留下一项新的选择或一段更鲜活的关系。无需每场都产出公事线索；读者知道两个人怎样吃饭、怎样记仇，也是在认识人物。

叙述保留宋的有力长句和带锋芒的对白。笑点允许落在一个动作、一句短答或沉默里，随后继续故事，不由旁白解释“众人这才知道她反将一军”。

## 三、人物组合怎样更好看

| 人物 | 喜剧中的性格与本事 | 适合的对手戏 | 须保留的情感重量 |
|---|---|---|---|
| 宋宛 | 好胜、嘴硬、安排欲强；公事灵敏，常把私人相处也想得太周全 | 与许争办法，与秦争经验，与女帝争最后一句，与姐姐争自己究竟有没有操心 | 想被看重，怕输一处便被否定全部；受关心时容易羞赧 |
| 燕昭宁 | 端得住皇帝架子，也会想多留一个人、多赢一句；擅挑出众人各自想要什么 | 御前让双方都领到差，私下让宋承认想去何处；韩能令她收住帝王口气 | 新君的孤独与依赖；她的判断能胜过宋，失约也须补偿 |
| 许明砚 | 直白、务实，最会让宋的漂亮打算碰见现场；本人也爱面子，逞强会被看穿 | 出发前不肯领空泛差命；归家时母亲只管她先吃面，不给她解释半日 | 想有自己的实职，也想回家；温柔留给愿意照顾的人 |
| 温廷章 | 老练，认得出宋来求帮忙前的客气；会留她坐，也会让她自己扛事 | 宋绕着说请求，温先把她将要递的难题说穿；下一次温也有事求宋 | 守遗命和信誉，真到危处肯承担，不能只剩损人台词 |
| 秦武 | 好面子、老经验、护营盘；被问中会恼，赢宋时也会得意 | 宋问账他不能躲，宋问军务他有办法；熟后可争鞋、饭量和谁先累 | 旧卒和当值有实际分量，签责和失察不能靠可爱免去 |
| 韩知微 | 平实，有生活经验；说一句家常话便能让女帝收住一段漂亮说辞 | 女帝认真许好处，韩先问家书能否照常寄、饭能否按时吃；相处中也能主动邀她 | 想家与想被亲近，不能只充当女帝的情绪解药 |
| 齐绍 | 拟强化为熟悉勋贵往来、讲体面又有个人愿望的成年世子 | 入宫后的长处真能帮忙，但想家族获益时会撞上女帝的条件；与韩从客气到互认一项本事 | 纳齐仍是拟议调整，本人愿意与真实政治成本须写成立 |
| 宋宜、姜令仪、梁素 | 姐姐有自己的经营，同窗知道宋的旧窘；三人的生活选择各不相同 | 姐妹说家里事，同窗说求学旧事、饭菜、课和出门；她们可以拒宋的建议，也会向她求助 | 女性友谊有暖意与合理摩擦，亲族旧伤和婚后负担有分量 |

人物活跃度随事件段变化。一段优先突出三至五个有利益冲突的人，其余自然退到生活或承接；避免所有人排队接同一句笑话。配角既能拆宋的招，也能帮她，宋也应有让朋友真心佩服和愿意靠近的时刻。

女帝后宫以政治合作与日常相处形成趣味：齐懂人情场面，韩懂日常与旧将生活；两人各有不愿让出的东西，也有共同难处。纳人仍由具体册命成立，不给后妃自动军权，不以把两人写笨或整日争宋的关注制造笑料。

## 四、全卷怎样轻快地推进

第一卷仍按约150章容量规划。段落之间用关系和成果承接，每段解决一个主要问题；手续和零碎回报让位于决定性冲突、实际所得与人物相处。

| 拟议区间 | 主事件 | 常态读感与阶段回报 |
|---|---|---|
| 1～7 | 先拜、验诏、分化宗亲、实际就藩 | 开篇告老有干涩幽默；灵前交锋有锋芒，保留丧仪分量；温的拒绝打开熟人趣味，沈母子戏保温情 |
| 8～15 | 新君第一次施政，平河庄门打开 | 朝堂各方想让别人付钱，现场不能用玩笑消掉伤害；胜利后让丈手和百姓有踏实喜悦，第一次施政成真 |
| 16～25 | 女帝纳妃争合作，宫里朝外开始共处 | 两位成年男子的本人意愿、礼序、外家要求与真实相处提供趣味；以合作实际兑现、女帝亲认一项难题结束 |
| 26～40 | 核实领、查军款，女相碰上老将 | 精选点名、找经手、揭虚报三场主要胜负；穿插第一次出差准备和返京后的不同讲法，删重复问件 |
| 41～50 | 补料与补偿落地，朋友和家人各得一项选择 | 公事有可见结果；宋宜第一次亲见自己的田，女学重聚有人晚到有人不等，父女相处留尴尬与一点关心 |
| 51～65 | 收束旧货与地方余责，开始形成接替 | 用有头有尾的回访和兑现收束旧线；姐姐会经营，同僚会独立决定，宋发现自己的提醒未必处处需要 |
| 66～85 | 北差、粮限、险桥、救粮实到 | 主危机集中、力度短而足；行装、旅途和饭桌可轻松，危险现场先救人；粮到后给守兵和出差者充分喘息 |
| 86～100 | 清旧偿、追双方责任、换班、归家 | 责任由京中和北地各承；把钱交到人手、把旧班换下来，随后回家吃面、看姐姐收麦，形成明亮回报 |
| 101～120 | 驻防办法、学军务，君臣逐渐争去留 | 宋第一次初拟被老将退，练脚力也会丢体面；女帝必须拿出自己的选择。宋的婚事可在这一段后部、约110章以后成为新压力 |
| 121～150 | 任用与接替，各人渐能自行办事 | 宋学会接受别人和她办得不一样，女帝学会真正授差；关系更熟，冲突更深，卷末兑现一项独立执行的成果 |

这些区间是重新安排的目标，不要求搬入当前对应章号的全部旧情节。尤其将宋的议亲后移时，原26～51中因议亲形成的邀请、名单、相看、停议与还图动机要一并调整，陆献图的公务来源重新成立；不能只删一章便让后文继续回应不存在的婚约。

宋婚事后期开启时，先让读者明白提出亲事能交换哪项任用、军需合作或留京支持，再写宋的反应。家庭相看可有尴尬趣味，政治施压的后果仍要真实。对象有独立欲望，不重复早段女帝选人的结构，见[婚姻线分布](婚姻线分布.md)。

## 五、三个可反复生长的生活线索

1. **宋的饭总等不齐人。** 初期是她说几句话便来，别人先吃；中段她终于早到，却替迟到朋友留饭；后段她能按时赴约，读者看见她真的开始放手。每次换人物和结果，避免固定“冷饭笑话”。
2. **她说是顺路。** 初期探亲不肯说想见，姐姐看破；中段朋友照样借口路过，带来她需要的东西；后段宋自己能约一个明确时辰。旁白不用反复揭穿。
3. **老将与文臣的脚。** 从宋以为自己能走，到秦也在宋熟悉的账上失手，再到她带来可用办法。鞋和脚只在有现场条件时出现，经验分歧随着人物成长改变。

这些是相处习性的候选写法，不设每几章必须出现一次。温的客气、韩的家书、姜的旧窘也可有自己的回声，但不把所有人物都限制为一个固定口头禅。

## 六、语气与场景的分寸

常态章节让人愿意跟着角色过日子。遇到丧亲、逼迫、伤病、断粮，先让事情得到有分量的处理；轻松感可在事前或事后由照顾、吃饭、团聚恢复。沈蘅安抚十一的夜戏保留，不因改喜剧就改成孩子插科打诨。

反对者能聪明、能抢到实际利益，也能心虚或怕丢脸。日常争执以当场吃亏、自己接差、公开改口或放弃一项便利形成回报；伤人、侵吞、失察等严重事实仍按相应权限处置。宋也要付出真实代价，喜剧中的难堪不能替代应有责任。

每三至五章宜有清楚进展，每个事件段至少有一处足够展开的胜利现场。严肃高潮集中在真正危险或两难的位置，其后安排成果与生活，避免每一章都反复压迫又反复安慰。笑点的密度服从场景，自然好笑可以多留一点；饭桌也允许只是饭桌。

对白先让人听懂，再留锋芒。古风用清楚、自然的词，不堆现代官场网络梗。喜剧可以由一句答非所问、提前吃饭或谁悄悄让了半步完成；人物没有必要每次都抖一句机灵话。

## 七、实施顺序

先以第1～7章确定两种能共存的声音：宋与熟人的轻快，继位与母子戏的分量。第1章保留已经有力的退奏、三元与插叙，不全面拆成问答；第5章用吃饼、拆来意与相互领事展开熟人交锋，第6章保留刚建立的母子情感。

前15章的当前交接见[前100章重构规划](前100章重构规划.md)，之后16～50继续让人物主动行动与生活篇幅支持主冲突。已有后50章通读后再按上述波段调整；当前钱粮、原件、授官与时序不能在规划阶段先改成新事实。

正文1～15章与简介采用喜剧语气；其余章按实际文件读取，后续改写直接落在`章节/`，同步索引、模块、人物和连续性；合章或改号发生时再统一整理目录，临时材料放项目外。
