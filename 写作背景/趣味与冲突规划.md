# 趣味与冲突规划

全书基调：轻松、强对抗、胜负回报鲜明的朝堂群像喜剧。年轻女帝要让满朝真正听令，好胜女相要让轻视她的人拿出真东西；一群有本事、有私心的人互相拆招，既争输赢，也一起过日子。宋建立接替、肯交相印，是她最终赢得选择去处的自由，呼应三十五岁致仕的开篇。

保留架空古代。宋宛与燕昭宁的本事、关系和判断来自本世经历，不加入穿越、重生、系统或预知。额外吸引力从已有制度和人物位置长出来，具体用法见下文。下文兼有已写场景与拟议方向，是否发生以正式正文与索引为准。

## 人物自己的日子

政治主轴与私人生活并行。温要留住故生的旧桌，许母想穿新鞋去挑菊，梁要给自己一条新裙，姜想看海，宋宜想与妹妹出门；这些愿望有自己的来处，也值得读者惦记。宋不在时，人物仍能相聚、误会、赌气和取乐。对手的护短同样有亲缘旧情，不能只在朝上生出一套反驳主角的道理。

生活允许独立成章并结束在生活里，闲话与玩笑无须回回改变局面。背景随当下亲近、退缩和习惯显露，不集中补履历；允许冲动、不体谅和不划算的选择，也留尚未想通的情绪。各人的已写生活与后续见[个人情节规划](人物关系与个人情节规划.md)。

## 政治主线的一轮戏

先让读者知道人物想赢什么：宋要拿回原票，旧将要保调度便利，侯府要争新朝信任，许要署自己的实绩。阻力随后落实为扣住东西、拒绝合作、抬高条件、抢先提案或争取旁人支持。主角据对手真正舍不得的利益设计反制，对方再出一招，最终有人交出便利、付出成本或接受新条件。

交锋可以用一处关键凭据翻局，也可以靠当场示范、拆开利益、找到替代人选或谈成交换。取证和军令仍有来源与权限，完整核验过程交给承办；正文重点呈现哪一处事实让谁原来的说法站不住，以及谁因此改变行动。

主角允许想赢、敢争、得意。宋认错后可以换办法再赢，秦反证成功后也要交出自己该交的部分；别让主角每次受挫都以自我教育收场。对手能赢一轮，败后仍有本事和余地，读者才会期待下回交手。

## 喜剧怎样持续

| 来源 | 出招与回手 | 要留下的变化 |
|---|---|---|
| 有本事的人互相不服 | 宋拿钱粮问住秦，秦拿守段和脚程回敬；宋学会后再带新办法来谈 | 双方各赢过，合作须重新议条件 |
| 自己说过的话找上门 | 朝臣倡节俭，女帝先请其说清本府肯省哪项；宋替人定日程，许请她亲走一遍 | 当场付出劳动、便利或体面，主张随之改变 |
| 体面与私心露了底 | 宋想多听一句夸奖，同窗偏先追借书；温愿结盟，先堵住她求全担保的话 | 既看穿又肯帮，各人领回自己的责任 |
| 高位也有不擅长的事 | 左相走路逞强，女帝约人却习惯下令，侯府争承运才发现车脚真要自出 | 当事人想补救，熟人趁机争到一个小条件 |
| 熟人各有算盘 | 宋迟到，朋友先吃；下次她提早来，却发现梁只留了自己能留的半日 | 互相迁就，也轮流得到照顾与便宜 |

熟人关系容得下嘴硬、偏心、闲闹与没用的小玩笑。许、姜、梁也会失算，宋既能回敬，也可以只陪着笑；别把每句玩笑排成一轮攻防，更不由笑话得出道理。丧亲、伤病和险途保留分量，普通生活同样有独立的乐趣，避免固定重复劝宋休息、教宋认错的组合。

## 爽点要有不同的所得

| 回报 | 现场怎样看见 | 后续怎样保住 |
|---|---|---|
| 反将一军 | 对手自提条件，宋补上对方也须履行的一半，让其当众表态 | 条件落到实际承办，下一次无法照旧推脱 |
| 拿到实权 | 女帝自己的任用与调度被执行，原来观望的人来认领差事 | 有人能接、有粮有款，执行后带来下一轮议价权 |
| 能力压场 | 宋找准关键差处、许在现场拿出办法、秦指出接防要害 | 得到署名、差职、合作条件或明确采纳 |
| 护短与讨回公道 | 郑二用本名领饷，马家实领恤银，商号拿到已挣的钱 | 当事人此后可以据凭办事，受损的生活确有改善 |
| 关系回报 | 朋友主动站在同一边，姐姐留一顿合口的饭，女帝承认自己想留人 | 下一次真给时辰、让出条件或承担代价 |
| 赢回自由 | 配角能自己挑差事、定婚姻、管经营；宋最终交印后真能走 | 接替者办成事，选择去处无需靠摧毁旧关系 |

重要胜利安排受阻、反制和可见所得，也留一点让读者享受的余味：对手改口、有人忍笑、伙伴争功、庆功饭终于吃成。胜利后再有新难题时，给本轮成果一句明确确认，别让下一张缺件单立刻吞掉它。

## 已有设定怎样更吸引人

| 设定 | 持续的戏剧用法 | 连续性边界 |
|---|---|---|
| 首位女帝与满朝旧臣 | 旧臣各自争祖制、军心、财权；女帝借各派分歧取得自己的任用与执行成果 | 宗室、勋贵各有立场，正常往来须有新凭据才能追为协同 |
| 女帝纳人与外家合作 | 齐家想凭出力换信任，韩想顾父亲又亲近女帝；家族想求便利，宫中人要亲口说自己的条件 | 齐韩均已成礼，同为良人；后续新请求另铺，不把亲近直接写成兵权或免罪 |
| 女学同窗进入不同位置 | 许争实绩、姜争选择、梁争教法和时辰，旧交既能结伴也会争名额、方法和体面 | 各人资格和现职照正文；姜梁不凭旧交得知密报，宋参与而不包办 |
| 年轻女相与旧将互相制衡 | 宋能卡住糊弄钱粮的说辞，秦能问倒纸上用兵；学会对方一部分本事后，下一轮争得更深 | 军务经验、京中接替与正式授令逐步建立，宋当前无军职 |
| 三十五岁告老与密旨悬念 | 读者追她如何从人人找的左相，变成能交印离开的人；阶段交接也是能力与自由的回报 | 未来插叙保留，密旨具体内容与转任时点须在正文逐步建立 |

宫廷、同窗和军政三种关系交错提供利益冲突与新鲜组合。宋宛的婚姻后移，到去留和权力分配确需筹码时再启动，依[婚姻线分布](婚姻线分布.md)推进。

## 第一卷节奏与回报

本节负责章节节奏；逐章名称与正文入口见[索引](章节索引.md)。安排以完整场景和人物自己的时间为依据，不固定每隔几章插一场生活。约好的出门、家人的归期、季节与一件想做的事，都能让生活自然接起；紧急行动尚未处置时，转场须让读者知道当事人怎样继续应对。

### 第1～15章的实际编排

| 区间 | 本段重心 | 速度与落点 |
|---|---|---|
| 1 | 盛年致仕的悬念，接差属官与宋的旧经历 | 先见人物锋芒和私人旧伤，再落到灵前无人肯拜；同时追去留与继位 |
| 2～4 | 读诏、押承诺、验真，让满朝遵诏 | 集中推进危机；宋有主动反制，百官拜下兑现胜利，丧父的分量留给女帝 |
| 5～7 | 温留旧桌、沈母子自择去处，宗室各领所需 | 从朝上转入书房、母子与兄妹，利益背后有念旧和不舍；就藩收束这一轮，保留新君独坐的感受 |
| 8 | 同窗完整看影戏、逛布摊，姜梁另谈海与新裙 | 留一整章过日子；春来核饷只作背景，章末落在朋友自己的愿望 |
| 9 | 姐妹出门挑头油，许主动请差却失约陪母 | 从亲近和玩笑转到许的兴奋与母亲的不快；清丈目标交代够用，临行牵挂留待后续 |
| 10 | 许初到平河，现场受阻，丈绳被割、样册起火 | 张力集中在地方，许从急于办成转为承认眼前未完；实报与家信交出当下选择 |
| 11 | 宋访许母，母已自行买菊；许收到回信 | 准缓、勘查与同勘照常承接，篇幅重在担心、陪坐与两地家常；母女仍未全说开 |
| 12～14 | 陆两次求撤，郑不敢出头，朝廷先保本人出来说话 | 冲突逐步加深，京县换场看见不同代价；陆家夫妻护短有来处，郑有过日子的恐惧，避免全段只剩殿上反驳 |
| 15 | 庄门打开、实亩落押、协办记功；姐妹相聚看戏 | 前半兑现成果，后半给生活完整收束；许仍在县里，姐姐仍试着处理自己的田，夜戏收尾后再接下一段 |

第9章挑香、未买的绣雀帕接第15章赠帕；许与母亲失约接母亲自行买花、两地回信。私人事情可以隔章继续，不要求当场和好或立即解决。第15章的政治成果已经明确，姐妹夜戏无需再添下一项催办来做章末钩子。

### 第16章以后的编排方向

16～100章已有正式正文，下表是继续修订时的节奏目标；101章起为待写方向。具体场景是否已发生，以正文及索引为准。

| 区间 | 主要争夺 | 喜剧与重要回报 |
|---|---|---|
| 16～24 | 女帝争合作，外家争信任与便利，兵部军门争核饷条件 | 本人开口谈入宫条件，实名点验与侯府交粮兑现；韩家相处、宫中磨合与许归家留足场景，几项成果分段落地 |
| 25～41 | 谁能拿出真经手、真粮数，谁能把成果记在自己名下 | 北差集中现场受阻与实查所得，压缩京中重复收报；同窗与姐妹自己的相约继续，许归来留下署名和团聚的回报 |
| 42～50 | 原验与报足正面冲突，各家争划清责任 | 关键凭据集中揭开虚报，退银实入库；父女赴约、同窗相聚可完整写，宋拒私席后留胜利余味再交补料问责 |
| 51～70 | 谁承担补料、恤银、误置和旧货拖延的代价 | 付钱、交铁、退税、承领和销讫交替兑现；家中与宫中有完整轻松场景 |
| 71～85 | 缺粮倒计时中，朝廷与军府都要别人先让步 | 粮限与险桥集中张力；商户能拒绝空许；粮真到，越权者付代价，守兵能吃饭 |
| 86～100 | 商号要清债，京中要推责，驻地要换班 | 旧债真清、京中也受处分、旧班真退；朋友归家与宋学走路恢复轻松，接下一轮驻防争夺 |
| 101～120 | 有限兵粮如何分守，各方谁出人、谁出粮、谁让权 | 宋拿初拟争主动，秦等提出军事反驳；修正后争到可执行方案，现场验证并见所得；婚事约110章后视矛盾需要引入 |
| 121～150 | 执行成果能否守住，换人后朝廷能否继续办事 | 能力与任用相配、主角赢得选择、各人生活有回报；卷末用独立执行的大成果收束 |

政治线上连续两三章受阻后应检查是否已有主动变化，一轮事件结束兑现重要回报。人物的私人事情在危机前便可开始，危机中有自己的进展，之后也未必都随公事一起圆满。公事每轮集中一个主问题，数额只留改变选择的一处。后续各卷随舞台扩大加强人事、军政与外部对抗，也让人物一直有自己的日子。
