# 写作资料阅读指引

正式正文为第1卷《拜见新君》第1～100章，下一章101；本卷约150章。帝相互换已落实1～30章，后续继续按重构规划推进；实际编号与已发生事实以正文为准。背景资料按下表分工维护，拟议场景落实后再登记进度。

| 文档 | 只负责什么 |
|---|---|
| [工作约定](../AGENTS.md) | 文件规则、写作要求与当前锚点 |

| [整体大纲](整体大纲.md) | 全书主轴、各线阶段与后续方向 |
| [连续性表](连续性核对表.md) | 时间、数额、物件、完成状态与未决事项 |
| [人物关系](人物关系定稿.md) | 姓名、身份、亲缘和同窗关系 |
| [人物档案](人物背景与关联.md) | 欲望、短处、说话方式与知情范围 |

写前读工作约定、互换设定和重构规划，再读实际索引、规范、整体大纲、连续性表与当前模块，再读相关正文和人物条目；续写通读最近三章。结构调整另读规划及简介。

一项事实只在负责文档详记，其余简述并链接。已结事项留结论，未决事项留进度、凭据和下一步；用新状态替换旧状态，临时材料放项目外。
