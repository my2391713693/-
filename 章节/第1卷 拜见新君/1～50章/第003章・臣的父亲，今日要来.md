# 第3章・臣的父亲，今日要来

宋宛第一反应，是请皇帝留在宫里。

“臣派人同家父说，今日有事。”

“你府里的人方才来送口信，人已经到了。”

燕昭宁说完，宋宛便觉得，父亲这辈子来得最快的一回，竟赶在了今日。

父亲宋敬修，原做户部郎中，早已致仕，仍很爱教女儿谨慎。宋宛少时赴女学，他叫守规矩；十七岁中三元，他叫莫得意；后来做了左相，他说为官更当慎重。

无论她到了哪一步，父亲总有一句能叫她退半步的话。

可他今日对着的，是个从小就有人替她报驾的皇帝。

宋宛赶紧把燕昭宁拉到一旁，声音压得极低。

“家父若说什么，陛下听着便是。不要忽然叫他站起来，也不要问他何时退下。”

燕昭宁的目光扫过她那只拽袖子的手。

宋宛立即松开。

“朕还不至于连见你父亲也不会。”

“那自然。”

她说得太快，女帝反而看了过来。

“你不信？”

宋宛很想再叮嘱两句，门外却已有人候着讲祭仪。她只得先把自己父亲交了出去，起身去听皇帝答应过的课。

——

燕昭宁用着宋宛的身体回到宋府时，宋敬修正在前厅坐着。

老者衣裳齐整，膝旁放一包书。看见她进门，先皱了眉。

“这样晚。”

燕昭宁停在门槛内。

她已经许多年没听人拿这三个字迎自己。

按往常，这时该有人解释陛下公务繁忙，再请来客起身行礼。可前厅安安静静，父亲等女儿回话，侍女等主人吩咐，竟没有一个想替她解这个围。

燕昭宁只好道：“宫里留了些时辰。”

“做臣子的，怎能把晚归都说成上头留人？”

她险些脱口说，确实是朕留的。

话到嘴边，硬生生改成：“是。”

宋敬修略松了眉，指指对面的座。燕昭宁坐下，侍女奉茶，她便将盏端起来。

父亲却还望着她。

她又把盏放下。

两人这样一来一回，谁也没喝成。

“今日朝上，”宋敬修终于问，“又同徐侍郎争了？”

燕昭宁想起徐荣那句恃宠专权，声音不觉冷了些：“该发的粮，他叫等着不发。”

“徐大人管了半辈子礼章，自有忧虑。你年轻，又受新君看重，越是如此，越不能叫人觉得仗势。”

燕昭宁抬眼。

“粮有，御批有，现行章程也没改。他若要问，可以问。为何非得守营的人先等？”

宋敬修显然没料到她今日答得这样快。往常女儿要么说得更细，要么干脆不说，留下那点不大高兴，让他自己看出来。

他将茶盖拨了一拨。

“我不是同你争粮。”

“那父亲想说什么？”

这声父亲，燕昭宁叫得比方才那声是还费力。

宋敬修看着她，过了一会儿，把旁边那包书推来。

“从前户部抄的旧例。里头有几处附注，你若用得上，看看。”

燕昭宁低头解绳。纸边磨旧，批注密密细细，不是来责她的奏本。

她翻了两页，不懂宋宛为何没有先告诉自己，父亲原来是来送书的。

宋敬修又道：“第三册有水利旧例，别同前两册混了。原本还留在家里，这些是另抄给你的。”

“多谢。”

老人点点头，目光落到她袖口那个小破处，刚要开口，燕昭宁已先把手藏了。

动作熟练得连她自己都意外。

宋敬修便改了话：“入宫穿成这样，总该补一补。”

这句她倒愿意认。

她原想替宋宛答应换件新的，转念又想，回头那人若问钱从哪里出，自己未必说得过，便只应了补好。

临走，宋敬修说初五家里无旁客，叫她回去吃顿饭。

燕昭宁犹豫半息。送书是真的，想见女儿也像是真的，宋宛却未必愿意由自己替她应。

“女儿把时辰理过，再给家里送话。”

老人神情淡下来，说随她，起身却仍叮嘱，第三册别夹错。

燕昭宁送他出门，回来坐了片刻，将三册书重新包齐，在最上头压一张纸。

父亲来过。书三册。初五的饭，未替你应。

写到最后一行，笔尖停住。

纸上是燕昭宁自己的字。

幸好没有叫旁人替她抄。

——

御书房里，宋宛终于听完祭仪。

她原以为自己在礼部议事时便算耐心，如今才知，站着等别人的人，至少还能说一句下官告退。

讲官收卷前又问今日有无疑问。

宋宛看见桌上厚厚的一叠仪程，实在不敢再有，十分诚恳地说：“明白了。”

讲官颇为欣慰，说明日便可讲后半。

原来今日还有前后之分。

她端起茶，想喝一口压住，内侍已叫人换膳。那碟核桃糕又端上来，比早上还新鲜。

宋宛望着它，半天没动。

宫人低声问，是不是不合口。

“早上那碟，还没用完吧？”

“膳房听说陛下喜欢，特意新做的。”

她终于明白，早上那半块咽得太痛快，痛快到膳房已经替自己安排了后半生。

宋宛将碟子往外推了推，又怕旁人回头挨训，索性说清：“不是糕不好。早上饿了，多用了些，往后照常备，不必顿顿送这个。”

宫人如释重负，收碟时还问明日是否撤下。

“明日让朕自己挑。”

这句总算落定了。

午后，她依早先约好，让内侍传宋相酉前带那包旧仪来，想再试一试合玦。燕昭宁赶在暮色前入宫，手里除了旧仪，还多出三册书。

宋宛一看包书的旧布，便坐直了。

“家父说什么了？”

“先嫌朕晚。”

“后来呢？”

“嫌朕不该将晚归推给上头。”

宋宛捧住茶盏，垂下头。等再抬起来，脸已经绷得十分辛苦。

燕昭宁把自己写的小纸条推给她：“想笑便笑。这是朕顶着你的脸挨的。”

“臣没有笑。”

“你这张脸，朕今日在镜里看过。忍不住的时候，眼角就是这样。”

宋宛终于笑出声，笑到燕昭宁把初五饭约也报了，才慢慢收住。

她打开书包，翻到第三册，看见父亲另抄的几行细字，指尖停了一阵。

“没替臣应，便好。”

“他像是想你回去。”

“臣知道。”

燕昭宁不再劝。她将旧仪铺到案上，宋宛把茶放到右手边，两人各拿起一枚玉玦。这回只试着合拢，再分开，没有谁敢先说愿意。

还是毫无用处。

宋宛正要问今晚难道也得这样过，远处暮鼓传来。

她眼前一晃，指下忽然换了触感。

玉玦仍在手里，座位却到了案子另一侧。身上的衣带熟悉了，掌心那颗浅痣也回来了。她猛地抬头，燕昭宁已从御座上站起。

两人一齐开口。

“回来了！”

门外内侍听见动静，连忙问陛下有何吩咐。

燕昭宁先吸一口气，才用自己原本的声音答：“无事。”

宋宛摸摸喉咙，觉得自己那件破官衣从没如此合身。她把玉放回匣中，又看见御座右侧那盏茶，终于知道方才不是坐错了地方。

衣服、玉、茶，都没有跟着人走。

她这回才真的敢伸长腿，靠到椅背上。

燕昭宁也坐下来，看向案边被她喝过半盏的茶，手伸到一半，又收回去，叫人换了两盏新的。

“祭仪听得如何？”

宋宛的腿立刻又收了回来。

“臣替您，”她道，“答应了明日接着听。”
